# Quaderni Cryptoverso

*English below.*

I quaderni pubblici dei libri Cryptoverso, da aprire su Colab o in locale:

- [`collana/`](collana/) — *Analisi ciclica falsificazionista* (*La prova dei cicli*, *Ciò che

# Cryptoverso notebooks

from them carry the same attribution and licence. Source, licence and transformations are in the
